# 手语知音使用说明

> 适用日期：2026年11月4日。本文分别说明本地完整版和线上独立站。按钮以当前界面为准，两个版本的数据和能力不互通。

## 一 先选对使用版本

| 版本 | 进入方式 | 适合做什么 |
| --- | --- | --- |
| 本地完整版 | http://127.0.0.1:8000/ | 示范标注、实时识别、预览纠错、后台训练、DeepSeek小助手 |
| 线上独立站 | https://signflow-practice-empty-20261104.craftytoad4096.chatgpt.site/ | 浏览器内录制、标注、预览、示范匹配与本地练习回顾 |

**两版不共享示范库。** 线上站从空白开始，不包含原项目的示范、录制和密钥；它尚未接入本地Python训练与DeepSeek。线上“更新识别库”与本地“重新训练”不是同一功能。

系统主要匹配你已经录入的动作，不是任意手语翻译器。“未可靠匹配”表示当前无法确认，不一定是你做错了。

## 二 第一次使用的推荐顺序

1. 打开本地完整版或线上独立站。
2. 在“我的手语示范库”中添加一个清楚、完整的动作。
3. 填写准确的含义并保存。
4. 打开示范预览，检查区间是否正确。
5. 用另一次录制完成相同动作，进行识别。
6. 如果结果错误，先预览对应动作，再纠正。
7. 本地版可在小助手中选择目标词，完成跟练和历史回顾。

先从少量词开始。同一个词尽量有多次独立录制，不要只把同一片段重复保存。

## 三 启动本地完整版

### 3.1 已安装环境时

1. 打开新仓库的 `SignFlow` 根目录。
2. 双击 `启动SignFlow.cmd`。
3. 等待服务完成启动，不要关闭服务窗口。
4. 在浏览器打开 http://127.0.0.1:8000/ 。
5. 进入“摄像头练习”“我的手语示范库”或“手语学习小助手”。

本仓库使用根目录的 `启动SignFlow.cmd`；请先按照README创建本仓库自己的虚拟环境。

### 3.2 检查服务是否正常

如果页面打不开，确认服务窗口没有退出，8000端口没有被旧服务占用。

可访问 http://127.0.0.1:8000/api/v1/health 检查运行状态。一般用户只需确认页面能正常加载，不需要修改程序。

### 3.3 结束使用

先停止实时识别并关闭摄像头。需要关闭本地服务时，再关闭启动窗口。

## 四 摄像头与拍摄准备

1. 在浏览器弹出的权限提示中允许摄像头。
2. 保持上半身与双手完整入镜，手不要贴到画面边缘。
3. 让手部占据足够画面，避免远景或教程录屏中的小窗。
4. 选择较明亮的位置，避免强烈逆光和快速运动造成模糊。
5. 每次完成一个完整词，保留起手、主要动作和收手。
6. 镜像通常只影响预览；不要因为画面翻转就随意交换标签。

骨架统一使用绿色显示。颜色相同不代表每个点都准确，异常和缺失信息仍可能影响识别。

## 五 上传视频建立示范

### 5.1 选择视频

1. 点击“我的手语示范库”入口。
2. 切换到“添加示范”。
3. 点击“上传新的示范视频”。
4. 选择视频，等待上传和骨骼分析完成。

本地版目前对视频大小、时长和分辨率有限制：最大80MB、120秒以内、最高4K。优先使用清楚的MP4视频，长教程请先剪成较短片段。

等待期间不要反复上传同一个文件。页面会显示处理状态。

### 5.2 标记一个完整动作

1. 播放视频到动作开始位置并暂停。
2. 点击“当前位置设为起点”。
3. 播放到动作结束位置并暂停。
4. 点击“当前位置设为终点”。
5. 点击“预览本区间”，检查是否包含完整动作。
6. 需要时使用播放倍速、起止时间输入框或旁边的微调按钮。

本地当前界面提供时间输入和微调控制；线上独立站提供±10ms按钮。微调单位以按钮文字为准。

起点必须早于终点，时间不能超过视频范围。不要为了凑一个短片段，只截取动作中间的静止姿势。

### 5.3 填写含义并保存

1. 在含义输入框中填写这个动作实际表达的词或短语。
2. 可选填写来源或镜像情况备注。
3. 点击“保存到示范库”。
4. 查看成功提示，并检查列表中是否出现新示范。

含义由你确认，系统不会自动证明教程标签的专业正确性。相同含义尽量使用一致写法，避免“谢谢”“感谢”等不同标签混用却没有明确区分。

### 5.4 一个视频保存多个词

保存第一段后，可以继续在同一视频中选择第二段，填写另一个含义并保存。

例如：

| 区间示例 | 标注含义示例 |
| --- | --- |
| 0.5—2.2秒 | 词语A |
| 3.0—4.8秒 | 词语B |
| 5.5—7.1秒 | 词语C |

这些只是时间示例，不是系统预置手语标签。

本地版保存后起点会接续到前一段末尾，仍应检查是否需要跳过讲解或停顿。自动分段建议仅供参考，不能替代完整动作检查。

### 5.5 继续标注已有视频

在“继续标注已有视频”中选择来源视频，重新设置区间并保存新词。也可以在相应条目中使用“定位”取用原区间。

线上版通过“继续标注已有视频”选择器或示范条目中的“继续标注此视频”操作。旧版没有保存原视频的条目，可能需要重新导入一次。

## 六 摄像头随录随标

### 6.1 本地完整版

1. 在示范库找到“随录随标”。
2. 点击“录一个手势”，允许摄像头访问。
3. 完成动作后点击“结束录制”。
4. 回放确认后，点击“进入分段标注”。
5. 等待视频分析完成。
6. 像上传视频一样设置起止、慢放预览、填写含义并保存。

本地随录随标最长15秒。同一段录制可以标注多个词，不会强制整段只保存一个词。

### 6.2 线上独立站

1. 开启摄像头。
2. 点击“录为示范”。
3. 做完后点击结束，或等待最长8秒自动结束。
4. 到示范库中设置区间、填写含义并保存。

线上视频和标注存放在当前浏览器。不要把它理解为已同步到本地Python服务。

## 七 管理与预览示范

### 7.1 查找示范

使用示范搜索框按含义查找。一个词可以有多条示范，列表显示的是示范数量，不一定是不同词的数量。

### 7.2 预览示范

点击条目旁的“预览”，或点击示范缩略图。

检查：

- 片段是不是目标动作；
- 起手和收手是否完整；
- 有没有混入讲解、其他动作或长时间停顿；
- 骨架是否基本贴合真实手；
- 标签是否确实对应这段动作。

预览支持倍速控制。新保存的线上示范可以回看原片与骨骼；旧条目未保存原片时，页面会提示。

### 7.3 待完善示范

如果显示“待完善”，说明资料虽然保存了，但当前特征不满足检索条件。根据提示调整区间，或改善拍摄条件后重新录制。

不要把“已经保存”当作“已经能够参与识别”。

### 7.4 删除示范

本地版：点击“删除”，再点击“确认删除”。

删除一条示范不会删除它的源视频，因为同一视频可能还有其他已标注词。线上版使用相应删除确认操作。

注意：删除示范不会自动删除同含义的其他示范、独立纠错样本或历史实验模型。如果仍能看到这个词的候选，可能是其他资料仍然存在。

## 八 本地实时识别

### 8.1 自动识别

1. 点击“开启摄像头”。
2. 点击“开始实时识别”。
3. 完成一个词后停顿片刻。
4. 查看右侧当前结果和候选。

画面中的骨骼用于观察检测是否跟上。候选列表是相似示范参考，不代表所有候选都被确认。

### 8.2 手动完整动作识别

自动切词不稳定时，优先使用：

1. 开启实时识别。
2. 点击“标记动作开始”。
3. 完成一个完整词。
4. 点击“结束并识别”。
5. 查看结果。

本地手动区间最长6.5秒。结束后保持手动模式，避免自动结果立即覆盖；需要切回时点击“恢复自动切词”。

这个流程可帮助区分“动作截取不完整”和“完整动作仍匹配错误”。

### 8.3 理解识别结果

| 输出 | 含义 | 建议 |
| --- | --- | --- |
| 某个词 | 当前比较满足接受条件 | 用另一次独立动作确认 |
| 未可靠匹配 | 不够接近或候选难区分 | 回看示范、检查区间与取景 |
| 候选参考 | 与若干示范较相似 | 不当成确定答案 |
| 有效信息不足 | 可比较特征较少 | 改善光线、手部大小与遮挡 |

距离越小表示当前特征下更接近，不是识别概率，也不是规范性分数。

### 8.4 线上站识别

线上版在摄像头区点击“开始一个动作”，做完后点击“做完了，识别”，最长8秒。

它采用浏览器内示范匹配，不是本地版后台引擎，也没有本地版完整的自动切词流程。

## 九 预览并纠正识别

### 9.1 先确认是哪次动作

点击“预览最近一次动作”。本地诊断预览主要显示已保存的骨骼动画，不含原始摄像头画面。较早记录没有保存关键点预览时会提示。

当前打开的预览固定绑定记录，不会被之后的新识别替换。

### 9.2 填写真实含义

确认片段确实包含完整动作，再填写实际表达的词。

如果动作明显被截断、只剩半只手或完全不清楚，建议重新录制，而不是强行标成一个正确词。

### 9.3 纠正并热更新

本地版可点击“确认动作完整，纠正并热更新”，也可使用主界面的纠正入口。

通过特征检查后：

- 纠错样本独立保存；
- 同一记录重复纠正会更新已有样本；
- 后续匹配可以使用新资料；
- 后台实验训练排队进行。

“热更新”不代表新神经网络立即上线。当前立即生效的主要是识别资料更新。

线上版在动作预览中点击“纠正并加入识别库”，立即用于浏览器内后续匹配，不执行Python训练。

## 十 重新训练

### 10.1 手动发起

在本地“我的手语示范库”标题旁点击“重新训练”。

适合在新增、删除或整理示范后，要求系统使用当前资料重新生成实验模型。

### 10.2 查看状态

- **等待训练**：任务已排队。
- **正在训练**：后台处理，原识别仍可使用。
- **完成**：显示样本数、类别数、验证数量与成绩。
- **失败**：检查资料是否足够、类别是否可划分，必要时查看后台日志。

训练期间按钮会防止反复提交。连续纠正可能合并为后续一轮训练。

### 10.3 正确认识成绩

训练集100%不代表摄像头准确。应重点看独立验证结果，并检查训练和验证来源是否隔离。

实验分类器目前不会因为训练结束就无条件替换在线示范匹配。删除一条示范也不意味着所有历史资料和同词纠错样本都已消失。

线上站的“更新识别库”是重新读取本浏览器示范，不等于训练神经网络。

## 十一 使用手语小助手

### 11.1 开始学习

1. 进入“手语学习小助手”。
2. 选择一个已有可用示范的词。
3. 点击“开始学习”。
4. 看一遍默认半速的示范，可点击“再看一遍”。

### 11.2 完成一次练习

1. 点击“我来试试”。
2. 小助手会准备摄像头和动作采集。
3. 做完后点击“做完了，看看反馈”。
4. 等待动作比较和反馈生成。
5. 根据建议点击“再练一次”或重看示范。

本地小助手约6秒会自动结束采集，避免超过分析窗口。按页面倒计时操作。

### 11.3 阅读反馈

主反馈采用日常语言，例如“这次和示范比较接近，再完整做一次试试”。

需要查看技术依据时，展开“练习记录与判断依据”。反馈是根据检测和比较生成的建议，不能当作专业手语教师的认证。

DeepSeek暂时不可用时，系统会使用本地规则反馈。

### 11.4 总结历史

点击“总结之前的练习”。小助手会回顾练过的词、次数和同次多轮练习中的变化，并建议下一次先练什么。

只有一次记录时，不能据此判断已经进步或稳定。历史回顾主要基于小助手中完成并保存的动作分析，不等于所有摄像头活动的完整统计。

线上站支持按浏览器练习记录进行规则回顾，尚未接入DeepSeek。

## 十二 数据保存与使用注意

### 本地完整版

示范、视频、诊断和训练资料在项目本地数据目录中保存。更换电脑或移动项目时，需一起备份必要的数据；只复制代码仓库不会自动带上数据库、视频与模型产物。

刷新页面前记录未保存的时间区间、词义等内容。数据库中的已保存条目与页面里尚未保存的输入不是一回事。

### 线上独立站

资料存储在当前浏览器中。不同浏览器、设备或隐私窗口不会自动共享。清理站点存储可能清除资料，当前没有云端同步承诺。

初次模型加载需要网络，数据录入与动作分析在浏览器处理。共享网址不会把你的本地示范库同步给其他访问者。

## 十三 常见问题

### 网站打不开

本地检查服务窗口和8000端口；线上检查网络与地址。不要连续启动多个本地服务占用同一端口。

### 摄像头无法开启

检查浏览器权限、系统摄像头权限和其他程序是否占用。线上摄像头应通过HTTPS网址访问；本地使用127.0.0.1。

### 已保存但无法识别

确认不是待完善条目，检查实际区间、标签一致性和手部清晰度。用不同录制测试，不要只测试刚保存的同一片段。

### 总偏向某个词

检查该词是否有包含长停顿、讲解或通用姿势的示范；预览误识别片段，填写真实含义。不要仅通过放宽阈值或大量重复保存同一片段解决。

### 骨架显示完整，还是认不准

关键点检测与词义匹配是不同环节。还可能存在区间、特征表达、视角、示范差异和候选混淆问题。

### 预览不是原视频

本地实时诊断主要保存关键点回放；示范预览则依赖源视频。线上新记录可保存浏览器内原片，旧记录可能缺少素材。

### 删除后还能认出同一个词

可能还有同义示范或独立纠错样本。重新训练并不等于自动清空这些资料，应先核对资料来源。

### 小助手没有历史总结

先在小助手中完成一次动作分析。只打开摄像头或只添加示范，不一定产生小助手练习记录。

### 操作时卡顿

暂停其他视频或训练密集任务，避免多开摄像头页面。识别匹配和后台训练仍会消耗计算资源，低性能设备需要更长等待。

## 十四 三分钟快速体验

1. 进入本地完整版，打开示范库。
2. 上传短视频或随录一段完整动作。
3. 标记区间，填写含义并保存。
4. 点击“预览”检查。
5. 在小助手选择同一个词，点击“开始学习”。
6. 看示范后点击“我来试试”，完成后结束。
7. 查看反馈；不准确时预览并纠正。
8. 需要时点击“重新训练”，并查看历史总结。

**最重要的操作原则：先确认示范与片段完整，再判断识别；先看实际验证结果，再判断模型是否改善。**
