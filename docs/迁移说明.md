# SignFlow独立整理说明

本仓库保留手语Python完整版，采用独立目录整理，未改动原Hand-Gesture-Recognition仓库。

## 保留

手语摄像头页面、示范标注、录制、预览纠错、识别库热更新、后台GRU训练、DeepSeek反馈与历史练习总结；手语流程调用的公共视频分析、追踪、分段、图解和版本组件。

## 不包含

手势舞前端、歌词服务与历史教程页面入口、私密.env、已有示范数据库、用户视频与摄像头录制、MediaPipe模型二进制、训练权重和私人实验结果。

## 新环境必做

创建本仓库虚拟环境；安装依赖；运行模型下载脚本；构建前端；按需配置自己的大模型API；重新导入示范，或自行在本机迁移经过确认的备份。默认不复制旧数据。

## 验证

整理后执行181项测试通过，独立前端构建成功。使用开发环境已有Python依赖验证；尚未在完全空白系统或容器中重新安装所有Python依赖。Docker配置为部署准备，未完成容器构建验证。
